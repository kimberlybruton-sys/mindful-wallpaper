# Mindful Wallpaper

A calm, minimal web app that displays soothing background visuals and short mindfulness reminders. Designed for quick moments of pause, breath, and reflection.

Whether you’re taking a short break between tasks or creating a more intentional, relaxed browsing experience, Mindful Wallpaper brings a little stillness into the screen.

## Why this project exists

This project was created as an approachable, beginner-friendly open-source project for people looking for calming digital experiences. The goal is simple: offer a gentle, beautiful interface that promotes mindfulness without requiring a login, complicated setup, or a large codebase.

## Features

- Rotating calming background visuals
- Short mindfulness prompts
- Previous / next navigation
- Shuffle mode
- Focus mode to hide the quote and simplify the experience
- Auto-rotate option
- Download current wallpaper
- Light/dark theme toggle
- Minimal, modern design with a Zen-inspired aesthetic

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
- No backend required

## Local setup

1. Clone the repository
2. Open the project folder
3. Navigate to the `mindful-wallpaper/` directory
4. Start a local server

Example:

```bash
cd mindful-wallpaper
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

Alternatively, you can open `index.html` directly in a browser for quick testing.

## How to use

- Click the arrows to move between images
- Use Shuffle for a new calming combination
- Toggle Focus mode to hide the quote and simplify the visual
- Turn on Auto-rotate for a serene slideshow effect
- Download the current background for personal use
