# Mindful Wallpaper

A tiny static site (inside the `mindful-wallpaper/` folder) that displays calming images with short mindfulness prompts. Built for beginners to learn HTML/CSS/JS.

Features (MVP)
- Next / Previous images
- Shuffle
- Focus mode (hides text)
- Auto-rotate
- Download current image

Quick start
1. Clone the repository
2. Navigate to `mindful-wallpaper/`
3. Add image files to `mindful-wallpaper/images/` (recommended names: `1.svg`, `2.svg`, ...)
4. Open `mindful-wallpaper/index.html` in your browser

Deploy
- To deploy with GitHub Pages from this repository, either move this folder to `docs/` or deploy the site from a `gh-pages` branch. I can help with either option.

Contributing
