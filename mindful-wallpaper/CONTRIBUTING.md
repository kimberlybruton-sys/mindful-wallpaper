Thanks for wanting to contribute!

How to run locally
1. Clone the repository
2. Navigate to `mindful-wallpaper/`
3. Put image files in the `mindful-wallpaper/images/` folder (1.svg, 2.svg, ...)
4. Open `mindful-wallpaper/index.html` in your browser

Good first issues
- Add 10 curated CC0/CC-BY images to the images/ folder
- Add an option to change quote font-size for accessibility
- Add a theme (light/dark overlay options)
